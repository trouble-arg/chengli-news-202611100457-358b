# 成理电讯

面向成都理工大学电气工程及其自动化专业学生的重要信息情报台。

## 启动

双击 `run.cmd`，浏览器会打开 `http://127.0.0.1:8765`。

如需手机在不同网络下访问，请按 `部署到手机.md` 使用 GitHub Pages 部署公开网址。

手动更新：

```powershell
python aggregator.py --refresh-only
```

注册 Windows 每日 08:00 更新任务：

```powershell
powershell -ExecutionPolicy Bypass -File install_daily_task.ps1
```

## 功能

- 自动聚合专业学习、校园机会、竞赛科研、专业就业、政策行业与四川热点
- 聚合科技媒体 RSS、能源行业官网、五类竞赛官网、就业平台、四川省政府及四川主流媒体
- 根据时效、关键词、来源与信息稀缺度计算重要度
- 生成简短概述，并保留完整原文链接
- 每 30 分钟自动更新，支持分类、搜索、排序、收藏和已读

如果浏览器仍显示空白，请先关闭旧的黑色控制台窗口，再重新双击 `run.cmd`；网站内的“刷新”按钮也会立即请求新的公开信息源。

数据缓存位于 `data/news_cache.json`，收藏与已读记录保存在浏览器本地。可编辑 `config.json` 调整主题、关键词权重和更新频率。

部分公开信息源在不同网络环境下可能暂时不可用。页面会如实显示同步状态，不使用虚构新闻冒充实时内容。
